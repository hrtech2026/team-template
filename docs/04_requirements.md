## Definition of Ready

- [ ] Пользователь и его роль определены
- [ ] Ценность описана в одну фразу
- [ ] Критерии приёмки сформулированы и проверяемы
- [ ] Зависимости от других историй перечислены
- [ ] Уровень автоматизации выбран и согласован с TO-BE
- [ ] Понятно, где история создаёт риск для человека

## Definition of Done

- [ ] Реализация проходит все критерии приёмки
- [ ] Для L1 и выше существует лог решения с объяснением
- [ ] Есть тест на граничные и ошибочные сценарии
- [ ] Права доступа настроены по ролям
- [ ] Документация для пользователя обновлена
- [ ] История просмотрена другим членом команды
- [ ] Риски ИИ для этой истории перепроверены, контрмеры работают
